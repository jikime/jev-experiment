# 테트리스 · Paper Edition

공식 **Tetris Guideline** 룰(테트리스 99·Tetris Effect·TETR.IO 등 현행 공식작이 쓰는 규격)을 그대로 쓰고, 화면만 종이 포스터 느낌의 네오브루탈 스타일로 새로 만든 웹 테트리스입니다. 설치할 의존성은 없습니다.

## 실행

`index.html`을 더블클릭하면 바로 플레이할 수 있습니다.

```bash
npm start      # 개발 서버 http://localhost:5173 (src/ 수정이 새로고침에 바로 반영)
npm run build  # src/ → dist/tetris.js 다시 묶기 (더블클릭 실행용)
npm test       # 규칙 엔진 테스트 + 번들 최신 여부 확인
npm run bench  # 봇 벤치마크 (Jev를 쓰면 API 비용이 든다 — 아래 참고)
```

브라우저는 `file://`에서 ES 모듈을 막기 때문에, 페이지는 `src/`를 일반 스크립트 하나로 묶은 `dist/tetris.js`를 읽습니다. `src/`를 고쳤다면 `npm run build`를 실행하세요. 개발 서버는 요청할 때마다 자동으로 다시 묶습니다. 포트는 `PORT=8080 npm start`로 바꿀 수 있습니다.

개발 서버는 기본으로 이 컴퓨터(`127.0.0.1`)에서만 열립니다. 같은 와이파이의 휴대폰으로 열려면 `HOST=0.0.0.0 npm start`를 쓰세요(이때는 Jev 프록시도 같은 네트워크에 열립니다).

## 대결 모드 (나 · Jev · 휴리스틱)

타이틀에서 **대결 시작**(또는 `V`)을 누르면 세 선수가 **같은 시드 = 같은 블록 순서**로 **같은 피스 수**(20·30·50·100)를 동시에 둡니다.

| 선수 | 두는 방법 |
|---|---|
| 나 | 키보드로 직접. **턴제**를 켜면 중력 없이, Space로 놓을 때까지 생각할 수 있다 |
| Jev | 코드가 착지 후보를 모두 만들고 결과를 말로 설명하면, [TypeSafe](https://docs.typesafe.ai) Jev가 `Choice` 질문 하나로 고른다. 확신도가 0.4보다 낮으면 자기 상위 후보 5개를 다음 피스 정보와 함께 **한 번 더 묻는다** |
| 휴리스틱 | 코드만. El-Tetris 가중치(높이·지운 줄·구멍·울퉁불퉁함)에 **다음 피스까지 보는 2수 탐색**, 턱 밑 **비틀어 넣기**·T-스핀 자리까지 찾는다 |

- 봇은 생각하는 동안 중력이 멈추고, 정한 동작을 `봇 속도` 간격으로 하나씩 실행합니다(기본 3, 동작 하나에 약 0.15초). 목표 자리는 빨간 점선으로 보입니다. 속도는 보이는 빠르기만 바꾸고 판단에는 영향이 없습니다.
- **Jev에게 전략 말하기**(선택): "오른쪽 끝 한 줄을 비워 두고 테트리스를 노려"처럼 적으면, 대결을 시작할 때 Jev가 문장을 정책(테트리스를 노리나 · 어느 쪽 줄을 비우나 · 위험을 얼마나 감수하나)으로 바꿉니다. "우물은 비워 둔다" 같은 **규칙은 코드가 지키고**, 그 안에서 어디에 놓을지는 Jev가 판단합니다. 휴리스틱은 전략을 따르지 않습니다.
- 끝나면 결과표에서 점수·줄·구멍·높이·판단 시간과 Jev의 평균 확신도, 휴리스틱과 같은 수를 둔 비율, 호출 수(다시 물은 수)와 추정 비용을 비교합니다. 순위는 완주한 선수가 먼저, 그다음 점수입니다.

### 벤치마크로 고른 설정

화면 없이 봇끼리 같은 시드로 두는 벤치마크가 있습니다. Jev 응답은 요청 해시로 `bench-out/cache.jsonl`에 저장돼, 같은 요청은 다시 돈을 내지 않습니다. 예상 비용이 `--max-cost`(기본 $0.5)를 넘으면 멈춥니다.

```bash
npm run bench -- --bots heuristic,jev-gate-look-drop --seeds 4242,7,777 --pieces 50
```

봇 이름은 `scripts/bench.mjs`의 `BOTS`에 있습니다. 확신도 구간별로 실수가 얼마나 몰리는지도 함께 출력합니다. 지금 설정은 이 결과로 정했습니다(50피스, jev-1.13.0).

| 바꾼 것 | 근거 |
|---|---|
| Jev 후보 설명을 "보드와 비교한 말"로, 보드 격자는 뺌 | 처음 버전은 38피스째 게임 오버. 바꾼 뒤 5시드 모두 완주, 평균 17.6줄 |
| 확신도 0.4 미만이면 다시 묻기 | 확신도 0.2~0.4 수의 20%가 피할 수 있던 구멍을 만들었고 0.8 이상은 2%. 다시 물으면 그 구간이 8%로 |
| 다시 물을 때만 다음 피스 정보 | 처음부터 넣으면 설명이 길어져 나빠짐(남은 구멍 2.2). 다시 물을 때만 넣으면 평균 18.2줄 |
| Jev는 위에서 떨어뜨리는 후보만 | 비틀어 넣기 후보까지 주면 후보가 늘어 구분이 어려워짐. 6시드에서 피할 수 있던 구멍 3.8 → 2.3 |
| 휴리스틱은 2수 탐색 + 비틀어 넣기 | 최고 높이 5.4 → 3.8 |
| 전략의 "우물 비우기"는 코드 규칙으로 | 우선순위로만 알려 주면 테트리스 0회. 규칙으로 지키면 6판에 7회(대신 50피스에선 지운 줄·점수가 줄어든다 — 우물을 쌓는 동안 줄을 덜 지우기 때문) |
| 전략 해석 경계값(테트리스 0.6, 위험 확신도 0.5) | 한국어 문장 5개로 확인. "크게 터뜨려"는 테트리스 여부가 정확히 0.50이라 켜지 않음 |

### Jev 연결

1. [TypeSafe 콘솔](https://console.typesafe.ai/keys)에서 API 키를 만듭니다.
2. `Tetris/.env`에 한 줄을 넣습니다 (저장소 루트 `.gitignore`가 이 파일을 제외합니다).
   ```
   TYPESAFE_API_KEY=발급받은_키
   ```
3. `npm start`로 연 페이지에서 대결을 시작합니다.

키는 브라우저로 가지 않습니다. 페이지는 개발 서버의 `/api/jev` 프록시만 부르고, 서버가 키를 붙여 `https://api.typesafe.ai/v1/systemone`으로 보냅니다(408·429·5xx는 최대 2회 재시도). 개발 서버는 `.env` 같은 점(.) 파일을 내려주지 않습니다. 키가 없거나 `index.html`을 더블클릭해 열었다면 Jev 자리는 비워 두고 나와 휴리스틱만 대결합니다. 모델은 **`jev-1.13.0`으로 고정**합니다. `jev-latest`는 새 버전이 나오면 가리키는 모델이 바뀌어 봇 실력이 예고 없이 달라질 수 있어서입니다. 새 버전을 시험할 때는 `TYPESAFE_DEFAULT_MODEL`로 바꾸고 벤치마크로 비교하세요.

비용은 피스 하나에 요청 하나(다시 물으면 둘), 입력 약 5~7천 토큰입니다(입력 100만 토큰당 $0.042, 출력 무료 기준 20피스에 약 $0.006, 50피스 벤치마크 한 판에 약 $0.015). 응답은 보통 0.2~0.3초이고, 기다리는 동안 Jev 레인은 중력이 멈추므로 느려도 결과는 같습니다. Jev 요청이 실패하면 그 수는 휴리스틱의 수로 대신 두고 `대체`로 셉니다.

## 룰 (Tetris Guideline)

- 10×20 필드 + 보이지 않는 버퍼 20줄, 스폰은 필드 바로 위
- SRS 회전과 월킥(I 전용 킥 테이블 포함), 7-bag 랜덤, 넥스트 5개, 고스트, 홀드
- 락 딜레이 0.5초, 바닥 접촉 후 이동·회전 15회까지 리셋(Extended Placement)
- 중력 `(0.8 − (레벨−1)×0.007)^(레벨−1)`초, 소프트 드롭은 20배, 레벨 20부터 20G
- 10줄마다 레벨 업
- 점수(× 레벨): 싱글 100 · 더블 300 · 트리플 500 · 테트리스 800 / T-스핀 미니 100·200 · T-스핀 400·800·1200·1600
- Back-to-Back ×1.5, 콤보 50×콤보, 퍼펙트 클리어 보너스
- T-스핀 판정: 3-코너 규칙, 앞 코너 2개 또는 5번째 킥이면 정식, 아니면 미니
- 게임 오버: Block Out(스폰 자리 막힘), Lock Out(필드 위에서 고정)

## 구조

```
src/core/     규칙 엔진 (DOM 없음, 테스트 대상) · placements.js(착지 후보 계산) · random.js(시드 난수)
src/ai/       heuristic.js(El-Tetris 봇·2수 탐색) · jev.js(Jev 요청·응답·다시 묻기) · strategy.js(말로 준 전략 → 정책)
              driver.js(봇이 Game을 조작) · simulate.js(화면 없이 한 판 — 벤치마크용)
src/ui/       캔버스 렌더러 · 입력(DAS/ARR·터치) · HUD · 효과음 · 저장
src/versus.js 대결 모드(세 레인·결정 카드·결과표)
src/main.js   화면 흐름(타이틀 → READY/GO → 플레이 → 일시정지/게임 오버·결과)
dist/         빌드 결과(tetris.js) — 직접 고치지 않는다
scripts/      build.mjs(의존성 없는 번들러) · serve.mjs(개발 서버 + Jev 프록시) · bench.mjs(봇 벤치마크)
              jev-client.mjs(.env·재시도 — 서버와 벤치마크 공용)
tests/        node:test 규칙·봇·번들 테스트 (Jev API는 부르지 않는다)
```
