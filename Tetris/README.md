# 테트리스 · Paper Edition

공식 **Tetris Guideline** 룰(테트리스 99·Tetris Effect·TETR.IO 등 현행 공식작이 쓰는 규격)을 그대로 쓰고, 화면만 종이 포스터 느낌의 네오브루탈 스타일로 새로 만든 웹 테트리스입니다. 설치할 의존성은 없습니다.

## 실행

`index.html`을 더블클릭하면 바로 플레이할 수 있습니다.

```bash
npm start      # 개발 서버 http://localhost:5173 (src/ 수정이 새로고침에 바로 반영)
npm run build  # src/ → dist/tetris.js 다시 묶기 (더블클릭 실행용)
npm test       # 규칙 엔진 테스트 + 번들 최신 여부 확인
```

브라우저는 `file://`에서 ES 모듈을 막기 때문에, 페이지는 `src/`를 일반 스크립트 하나로 묶은 `dist/tetris.js`를 읽습니다. `src/`를 고쳤다면 `npm run build`를 실행하세요. 개발 서버는 요청할 때마다 자동으로 다시 묶습니다. 포트는 `PORT=8080 npm start`로 바꿀 수 있습니다.

| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 (DAS 167ms / ARR 33ms) |
| ↑ · X | 시계 방향 회전 |
| Z · Ctrl | 반시계 방향 회전 |
| ↓ | 소프트 드롭 (1점/칸) |

터치 기기에서는 화면 아래 버튼 패드가 나타납니다.

## 룰 (Tetris Guideline)

- 10×20 필드 + 보이지 않는 버퍼 20줄, 스폰은 필드 바로 위
- SRS 회전과 월킥(I 전용 킥 테이블 포함), 7-bag 랜덤, 넥스트 5개, 고스트, 홀드
- 락 딜레이 0.5초, 바닥 접촉 후 이동·회전 15회까지 리셋(Extended Placement)
- 중력 `(0.8 − (레벨−1)×0.007)^(레벨−1)`초, 소프트 드롭은 20배, 레벨 20부터 20G
- 10줄마다 레벨 업
- 점수(× 레벨): 싱글 100 · 더블 300 · 트리플 500 · 테트리스 800 / T-스핀 미니 100·200 · T-스핀 400·800·1200·1600
- Back-to-Back ×1.5, 콤보 50×콤보, 퍼펙트 클리어 보너스
- T-스핀 판정: 3-코너 규칙, 앞 코너 2개 또는 5번째 킥이면 정식, 아니면 미니
- 게임 오버: Block Out(스폰 자리 막힘), Lock Out(필드 위에서 고정)

## 구조

```
src/core/   규칙 엔진 (DOM 없음, 테스트 대상)
src/ui/     캔버스 렌더러 · 입력(DAS/ARR·터치) · HUD · 효과음 · 저장
src/main.js 화면 흐름(타이틀 → READY/GO → 플레이 → 일시정지/게임 오버)
dist/       빌드 결과(tetris.js) — 직접 고치지 않는다
scripts/    build.mjs(의존성 없는 번들러) · serve.mjs(개발 서버)
tests/      node:test 규칙·번들 테스트
```
