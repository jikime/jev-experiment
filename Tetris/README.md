# 테트리스 · Paper Edition

공식 **Tetris Guideline** 룰(테트리스 99·Tetris Effect·TETR.IO 등 현행 공식작이 쓰는 규격)을 그대로 쓰고, 화면만 종이 포스터 느낌의 네오브루탈 스타일로 새로 만든 웹 테트리스입니다. 설치할 의존성은 없습니다.

## 실행

`index.html`을 더블클릭하면 바로 플레이할 수 있습니다.

```bash
npm start      # 개발 서버 http://localhost:5173 (src/ 수정이 새로고침에 바로 반영)
npm run build  # src/ → dist/tetris.js 다시 묶기 (더블클릭 실행용)
npm test       # 규칙 엔진 테스트 + 번들 최신 여부 확인
```

브라우저는 `file://`에서 ES 모듈을 막기 때문에, 페이지는 `src/`를 일반 스크립트 하나로 묶은 `dist/tetris.js`를 읽습니다. `src/`를 고쳤다면 `npm run build`를 실행하세요. 개발 서버는 요청할 때마다 자동으로 다시 묶습니다. 포트는 `PORT=8080 npm start`로 바꿀 수 있습니다.

개발 서버는 기본으로 이 컴퓨터(`127.0.0.1`)에서만 열립니다. 같은 와이파이의 휴대폰으로 열려면 `HOST=0.0.0.0 npm start`를 쓰세요(이때는 Jev 프록시도 같은 네트워크에 열립니다).

## 대결 모드 (나 · Jev · 휴리스틱)

타이틀에서 **대결 시작**(또는 `V`)을 누르면 세 선수가 **같은 시드 = 같은 블록 순서**로 **같은 피스 수**(20·30·50·100)를 동시에 둡니다.

| 선수 | 두는 방법 |
|---|---|
| 나 | 키보드로 직접 (일반 게임과 같은 중력) |
| Jev | 코드가 착지 후보를 모두 만들고, [TypeSafe](https://docs.typesafe.ai) Jev가 `Choice` 질문 하나로 그중 하나를 고른다 |
| 휴리스틱 | 코드만. El-Tetris 가중치(높이·지운 줄·구멍·울퉁불퉁함)로 가장 점수가 높은 후보 |

- 봇은 생각하는 동안 중력이 멈추고, 정한 동작을 `봇 속도` 간격으로 하나씩 실행합니다. 목표 자리는 빨간 점선으로 보입니다.
- Jev에게는 보드 격자 대신, 후보마다 코드가 계산한 결과를 **말로 된 구간**으로 넘깁니다: 어디에 놓이는지(가장 낮은 곳 / 가장 높은 곳 위), 가장 높은 열이 몇 줄 오르는지, 표면이 평평해지는지, 지우는 줄, 새 구멍. 숫자 비교는 코드가, 판단은 Jev가 하도록 나눈 것입니다.
  - 처음 버전(설명이 거칠고 보드 격자 포함)은 중반부터 후보들이 똑같아 보여 확신도가 0.1대로 떨어지고 가운데에 탑을 쌓다 38피스째 게임 오버가 났습니다. 지금 버전은 시드 3개 × 50피스에서 모두 완주했습니다(평균 확신도 0.61~0.63, 휴리스틱 1순위와 72~76% 일치).
- 봇 속도 기본값은 3(동작 하나에 약 0.15초)이고, 피스를 놓은 뒤 잠깐 멈춰 결정 카드를 읽을 수 있게 합니다. 속도는 보이는 빠르기만 바꾸고 봇의 판단에는 영향이 없습니다.
- 끝나면 결과표에서 점수·줄·구멍·높이·판단 시간과 Jev의 평균 확신도, 휴리스틱과 같은 수를 둔 비율, 호출 수와 추정 비용을 비교합니다. 순위는 완주한 선수가 먼저, 그다음 점수입니다.

### Jev 연결

1. [TypeSafe 콘솔](https://console.typesafe.ai/keys)에서 API 키를 만듭니다.
2. `Tetris/.env`에 한 줄을 넣습니다 (저장소 루트 `.gitignore`가 이 파일을 제외합니다).
   ```
   TYPESAFE_API_KEY=발급받은_키
   ```
3. `npm start`로 연 페이지에서 대결을 시작합니다.

키는 브라우저로 가지 않습니다. 페이지는 개발 서버의 `/api/jev` 프록시만 부르고, 서버가 키를 붙여 `https://api.typesafe.ai/v1/systemone`으로 보냅니다(408·429·5xx는 최대 2회 재시도). 개발 서버는 `.env` 같은 점(.) 파일을 내려주지 않습니다. 키가 없거나 `index.html`을 더블클릭해 열었다면 Jev 자리는 비워 두고 나와 휴리스틱만 대결합니다. 모델은 `TYPESAFE_DEFAULT_MODEL`로 바꿀 수 있습니다(기본 `jev-latest`).

비용은 피스 하나에 요청 하나, 입력 약 5~7천 토큰입니다(입력 100만 토큰당 $0.042, 출력 무료 기준 20피스에 약 $0.006). 응답은 보통 0.2~0.3초이고, 기다리는 동안 Jev 레인은 중력이 멈추므로 느려도 결과는 같습니다. Jev 요청이 실패하면 그 수는 휴리스틱의 수로 대신 두고 `대체`로 셉니다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 (DAS 167ms / ARR 33ms) |
| ↑ · X | 시계 방향 회전 |
| Z · Ctrl | 반시계 방향 회전 |
| ↓ | 소프트 드롭 (1점/칸) |
| Space | 하드 드롭 (2점/칸) |
| C · Shift | 홀드 (피스당 1회) |
| Esc · P | 일시정지 |
| M | 효과음 켜기/끄기 |

터치 기기에서는 화면 아래 버튼 패드가 나타납니다.

## 룰 (Tetris Guideline)

- 10×20 필드 + 보이지 않는 버퍼 20줄, 스폰은 필드 바로 위
- SRS 회전과 월킥(I 전용 킥 테이블 포함), 7-bag 랜덤, 넥스트 5개, 고스트, 홀드
- 락 딜레이 0.5초, 바닥 접촉 후 이동·회전 15회까지 리셋(Extended Placement)
- 중력 `(0.8 − (레벨−1)×0.007)^(레벨−1)`초, 소프트 드롭은 20배, 레벨 20부터 20G
- 10줄마다 레벨 업
- 점수(× 레벨): 싱글 100 · 더블 300 · 트리플 500 · 테트리스 800 / T-스핀 미니 100·200 · T-스핀 400·800·1200·1600
- Back-to-Back ×1.5, 콤보 50×콤보, 퍼펙트 클리어 보너스
- T-스핀 판정: 3-코너 규칙, 앞 코너 2개 또는 5번째 킥이면 정식, 아니면 미니
- 게임 오버: Block Out(스폰 자리 막힘), Lock Out(필드 위에서 고정)

## 구조

```
src/core/     규칙 엔진 (DOM 없음, 테스트 대상) · placements.js(착지 후보 계산) · random.js(시드 난수)
src/ai/       heuristic.js(El-Tetris 봇) · jev.js(Jev 요청·응답) · driver.js(봇이 Game을 조작)
src/ui/       캔버스 렌더러 · 입력(DAS/ARR·터치) · HUD · 효과음 · 저장
src/versus.js 대결 모드(세 레인·결정 카드·결과표)
src/main.js   화면 흐름(타이틀 → READY/GO → 플레이 → 일시정지/게임 오버·결과)
dist/         빌드 결과(tetris.js) — 직접 고치지 않는다
scripts/      build.mjs(의존성 없는 번들러) · serve.mjs(개발 서버 + Jev 프록시)
tests/        node:test 규칙·봇·번들 테스트 (Jev API는 부르지 않는다)
```
